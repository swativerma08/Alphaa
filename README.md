# AlphaaTechify

A lightweight React + Vite presentation site with a React Three Fiber scene, scroll-driven storytelling, and a polished connection experience.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project notes

- `src/` contains the complete application source.
- `public/` contains only production assets used by the site.
- `node_modules/` and `dist/` are intentionally excluded from the delivery ZIP.
- The 3D scene is powered by React Three Fiber / Drei.
- The connection form is currently a front-end interaction demo; connect it to your preferred API/email service before production use.
